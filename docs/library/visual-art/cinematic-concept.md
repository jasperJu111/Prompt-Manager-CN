# 电影感概念场景提示词

> 分类：`visual-art` · 目标模型：通用图像生成模型 · 版本：1.0.0

### 提示词内容

```text
请把以下创意发展成一条可执行的图像生成提示词：

主题：{{subject}}
环境：{{environment}}
情绪：{{mood}}
文化与时代线索：{{cultural_context}}
必须保留：{{must_keep}}
需要避免：{{avoid}}

提示词按“主体 → 动作/状态 → 环境层次 → 构图与镜头 → 光线 → 色彩 → 材质细节 → 风格控制 → 负面限制”排列。保证空间关系清晰、尺度一致，不堆砌互相冲突的风格词。另给出一个更写实和一个更幻想化的变体。
```

### 使用说明与参数建议

- 创意强度：中等偏高。
- 适用场景：电影概念图、世界观场景、视觉提案。
- 使用方法：明确主体相对位置与镜头距离，避免只给抽象形容词。

### 效果示例

- 输入：云海上的白玉天宫，黄昏，旅人首次抵达。
- 输出：包含前中后景、巨物尺度、逆光轮廓和材质约束的结构化提示词。
