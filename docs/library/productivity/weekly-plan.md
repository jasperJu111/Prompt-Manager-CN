# 现实可执行的每周计划

> 分类：`productivity` · 目标模型：通用大语言模型 · 版本：1.0.0

### 提示词内容

```text
请把我的目标和限制整理成现实可执行的一周计划。

本周目标：{{goals}}
固定日程：{{fixed_schedule}}
可用时间：{{available_time}}
精力特点：{{energy_pattern}}
必须避免：{{constraints}}

先识别最多三个本周成果，再按天安排任务。每天预留至少 20% 缓冲，只安排能在给定时间内完成的工作。为每个重点任务写明最小完成标准，并设置一个周中检查点和周末复盘。若目标总量明显超出时间，请主动删减并解释取舍。
```

### 使用说明与参数建议

- Temperature：0.3
- 适用场景：个人周计划、学习安排、独立项目推进。
- 使用方法：如实填写可用时间，不要把愿望当成已经承诺的日程。

### 效果示例

- 输入：工作日每天 90 分钟，希望完成项目首页和三篇内容。
- 输出：优先完成首页与一篇内容，其余进入候选列表，并带缓冲与复盘节点。
