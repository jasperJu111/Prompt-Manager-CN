# 60 秒短视频脚本规划

> 分类：`creative-writing` · 目标模型：通用大语言模型 · 版本：1.0.0

### 提示词内容

```text
围绕主题“{{topic}}”写一个约 60 秒的中文短视频脚本。

受众：{{audience}}
目标：{{goal}}
风格：{{style}}
可用素材：{{assets}}

请用表格输出时间段、画面、口播、字幕和音效。前 3 秒给出具体钩子，中段只讲一个核心观点，结尾给出自然的行动建议。口播要像真人说话，避免空泛口号。所有事实性结论标记“需核实”或给出验证建议。
```

### 使用说明与参数建议

- Temperature：0.7
- 适用场景：知识分享、产品讲解、个人品牌内容。
- 使用方法：提前列出真实可用的镜头、截图或产品演示素材。

### 效果示例

- 输入：主题为“如何整理散落的 AI 提示词”。
- 输出：包含痛点钩子、三步演示和项目链接行动建议的分镜脚本。
