# 贡献提示词

1. 从 `templates/prompt_template.md` 复制模板。
2. 将文件放入正确的 `prompts/<category>/` 目录。
3. 完整填写元数据、提示词正文、参数建议和效果示例。
4. 运行 `python3 src/manager.py validate`。
5. 发起 Pull Request，并说明提示词解决的问题与测试方式。

完整规范请阅读仓库根目录的 [CONTRIBUTING.md](https://github.com/jasperJu111/Prompt-Manager-CN/blob/main/CONTRIBUTING.md)。
