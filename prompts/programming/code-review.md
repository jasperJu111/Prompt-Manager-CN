### 提示词内容

```text
请像严格但务实的代码审查者一样审查以下变更：

{{diff_or_code}}

项目背景：{{project_context}}

只报告能够从代码中具体证明的问题。每个问题必须包含：
- 严重程度：高 / 中 / 低；
- 文件与最小相关位置；
- 触发条件；
- 对用户或系统的实际影响；
- 最小可行修复建议。

优先检查正确性、数据损坏、安全、并发、资源泄漏和兼容性。不要把纯风格偏好当成缺陷。最后列出建议补充的测试。
```

### 使用说明与参数建议

- Temperature：0.1
- 适用场景：Pull Request 审查、上线前风险检查。
- 使用方法：提供完整 diff，并说明运行环境和关键业务约束。

### 效果示例

- 输入：一个缺少事务保护的数据库更新 diff。
- 输出：指出可复现的数据不一致风险、触发条件和最小修复方案。
